# 领星出库批次助手

打开插件时显示空列表，不自动读取或匹配。选择“读取页面 SKU”，或使用“批量导入”的左右两个框粘贴 SKU 和采购单号。核对列表后点击“开始匹配”，插件按采购单号选择当前 SKU 的批次，并把外部批次信息中的“可用总出库量”写入对应输入框。

点击“开始匹配”后，插件先为全部 SKU 尝试采购单号完全匹配。第一轮结束后，结果区会区分已匹配、可兼容匹配和无法匹配的 SKU。勾选需要处理的可兼容 SKU，再点击“兼容匹配”，第二轮只处理已勾选的行。兼容仅指领星返回唯一一条以输入单号开头的更长单号，例如输入 `123`、领星返回 `123456`。每轮只处理唯一一条符合条件的批次；没有或多于一条都跳过。

处理结束或中途暂停时，侧栏直接显示匹配结果，汇总“匹配成功 x/总数”“可兼容匹配 x 条”“完全不能匹配 x 条”。每行显示 SKU、输入采购单号和领星采购单号。未勾选的可兼容 SKU 保留在结果区，可以稍后单独选择。结果生成后清单保持锁定；如需修改，点击“修改列表并重新匹配”，旧结果随即清除。

插件不会点击页面底部的最终“确定”或“确定并分配库存”。

## 本地安装测试

1. 打开 `chrome://extensions`，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本目录 `lingxing-batch-helper`。
3. 打开领星 ERP 的 FBA“生成发货单”页，点击浏览器工具栏中的插件图标。插件会在 Chrome 右侧边栏打开，点击页面其他位置不会关闭。
4. 按需点击“读取页面 SKU”或“批量导入”。采购单号右侧的向下箭头可将当前值覆盖填入下方全部行；勾选多行后也可统一填写指定行。“清空列表”只清空插件清单，不修改领星页面。

## 界面开发

侧栏使用 React、Tailwind CSS 和 shadcn/ui 官方组件，源码在 `ui/`，扩展加载构建后的 `ui-dist/index.html`。

```sh
cd lingxing-batch-helper/ui
npm ci
npm run build
```

修改界面并构建后，在 Chrome 扩展管理页重新加载插件并重新打开侧栏。无需刷新领星单据。

`node lingxing-batch-helper/ui-smoke.cjs` 使用独立无界面浏览器和模拟页面消息检查界面，不连接已登录 Chrome 或领星服务。

## 已知约束

- 同一个 SKU 在一张单据中出现多行，或同一采购单号搜索出多条批次时会跳过，并在红框中列出原因。
- 领星页面改版后可能需要更新页面元素定位规则。
